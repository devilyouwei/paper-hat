How is each entry scored?

The Hippocampus uses a single-signal uncertainty gate (paper §3.4.2): 

score(m) = U(m)    ·    write if U ≥ threshold

A trace is written to the Neocortex when the cortex's uncertainty on its own response meets the threshold. Corrections are no longer a separate field — they surface as the next user turn in the same session and the abstractor's router prompt decides whether to REVISE the existing trace or CREATE a new one.

U uncertainty How unsure the model is about its own response. 1 − exp(mean log p) over the response tokens (logprob path), fallback 0.5 when the backend has no logprobs.
