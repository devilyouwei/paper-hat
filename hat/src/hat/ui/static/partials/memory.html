Entries written here are the SFT training set for the Cortex. Edit or delete rows to manually curate the data before the next sleep-phase trainer run.

How is each entry scored?

The Hippocampus fuses three per-interaction signals into a single scalar via a linear write policy (paper §3.4.2): 

score(m) = α·U(m) + β·F(m) + γ·N(m)

A trace is written to the Neocortex when score > threshold. There is one hard override: a verified user correction (F = 1) is always accepted regardless of the soft score — the user is the teacher of last resort.

signalweightmeaninghow it's computed
U uncertainty — How unsure the model is about its own response. 1 − exp(mean log p) over the response tokens (logprob path), fallback 0.5 when the backend has no logprobs.
F feedback — Strength of the user's supervision signal. 1.0 if a correction was supplied, otherwise the explicit feedback field, else an LLM judge of implicit cues.
N novelty — How new the user input is to the model — never evaluated against the model's own response. LLM self-assessment under a strict prompt that ignores truthfulness, legality, and sensitivity; it judges only "do I, the model, already know this?".
